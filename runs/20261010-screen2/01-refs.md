# S1 레퍼런스 분석 — 화면 2

> 검색 키워드: 달력, 루틴 카드

## 미니모어맥스 — 기록 내역 월 달력 (날짜 아래 점 표시)
- ui_url: https://uibowl.io/name/%EB%AF%B8%EB%8B%88%EB%AA%A8%EC%96%B4%EB%A7%A5%EC%8A%A4?patterns=%EB%82%B4%EC%97%AD&patternName=%EB%8B%AC%EB%A0%A5
- 관찰: 상단에 "2024년 10월" 연월 제목과 좌우 화살표로 월 이동, 그 아래 요일 헤더와 7열 날짜 그리드. 기록이 있는 날짜 숫자 아래에 작은 점 1~2개가 찍히고, 선택된 날짜는 흰 알약 모양 배경으로 강조된다. 그리드 외에 장식 요소가 거의 없어 날짜와 점만으로 기록 유무가 한눈에 읽힌다.
- 반영 포인트: 월 달력 뷰에서 기록이 있는 날짜를 숫자 아래 작은 점으로 표시하는 방식을 가져온다 (PRD "기록이 있는 날짜 표시 (점 또는 색상)").
- 반영 포인트: 연월 제목 + 좌우 화살표로 월 이동, 선택 날짜는 알약형 배경으로 강조하는 구조를 가져온다. 다크 배경은 쓰지 않고 design.md 토큰 색으로 바꾼다.

## 열품타 — 월 달력 목록 (오늘 날짜 원형 강조 + 날짜 칸 내 요약 칩)
- ui_url: https://uibowl.io/name/%EC%97%B4%ED%92%88%ED%83%80?patterns=%EB%AA%A9%EB%A1%9D%20%28PLP%29&patternName=%EB%8B%AC%EB%A0%A5
- 관찰: 화면 상단 "6월" 월 제목 아래 월~일 요일 헤더와 큰 날짜 칸 그리드. 오늘 날짜는 검은 원 안의 흰 숫자로 강조되고, 날짜 칸 안에 기록 시간·일정이 색 칩으로 들어간다. 주말·다른 달 날짜는 옅은 회색으로 구분된다. 하단에 둥근 탭 바가 떠 있는 형태.
- 반영 포인트: 오늘 날짜는 원형 배경으로, 다른 달 날짜는 보조 텍스트 색으로 낮춰 위계를 나누는 방식을 가져온다.
- 반영 포인트: 날짜 칸 안에 긴 칩을 넣으면 390 폭에서 글자가 잘리므로, 칸 안에는 점만 두고 요약은 달력 아래 별도 영역에 보여주는 쪽으로 정리한다.

## 오늘의 루틴 — 주간 날짜 줄 + 루틴 목록 카드 (주기·남은 일수 라벨)
- ui_url: https://uibowl.io/name/%EC%98%A4%EB%8A%98%EC%9D%98%20%EB%A3%A8%ED%8B%B4?patterns=%EC%83%81%EC%84%B8%EC%A0%95%EB%B3%B4%20%28PDP%29&imgId=cmqj72wpq001ljr0445g9djah
- 관찰: 상단에 요일+날짜 원형 칸 7개가 가로로 놓이고 각 원 둘레에 진행률 링이 그려진다. 선택 날짜는 채워진 색 원으로 강조. 그 아래 상태 필터 칩(전체·미완료·완료 등)과 루틴 목록 카드가 있고, 카드 행마다 루틴명 오른쪽에 "격일 1/8일", "D-2" 같은 주기·남은 일수 라벨이 붙는다. 카드를 누르면 아래에서 시트가 올라와 상세 보기·진행 현황·오늘의 기록·수정하기·루틴 끝내기·삭제하기 메뉴를 보여준다.
- 반영 포인트: 루틴 카드에 루틴명 + 사용 주기(매일/격일/주 N회/자유) 라벨 + 다음 예정일까지 남은 일수(D-n)를 한 줄에 함께 보여주는 구성을 가져온다.
- 반영 포인트: 루틴 카드 메뉴에서 주기 수정과 "루틴 끝내기"(종료·아카이브)로 진입하는 흐름을 참고한다. 주기가 '자유'인 카드는 D-n 라벨을 빼고 최근 기록일만 표시한다.
- 제외: 시트 상단의 외부 광고 배너, "잠시 쉬어가기" 일시정지 기능은 PRD 범위 밖이라 가져오지 않는다.

## 앳플리 — 오늘 기록 대시보드 (섹션별 요약 카드 + 루틴 목록)
- ui_url: https://uibowl.io/name/%EC%95%B3%ED%94%8C%EB%A6%AC?patterns=%EB%AA%A9%EB%A1%9D%20%28PLP%29&imgId=cmtpokkuu00qwl7044ls5pogv
- 관찰: 상단 좌측에 "9.03 목" 날짜 선택 드롭다운, 우측에 달력 아이콘. 아래로 둥근 모서리의 흰 카드가 섹션별(몸무게·운동·식단·감정·루틴 목록)로 쌓이고, 각 카드는 제목 + 큰 숫자 요약 + 보조 설명 구조다. 기록이 없는 섹션은 "기록 0건" 같은 빈 상태 문구와 + 버튼을 보여준다. 맨 아래 "루틴 목록 3건" 카드에 루틴/오늘 할 일 세그먼트 토글이 있다.
- 반영 포인트: 날짜를 탭했을 때 그날 기록 요약을 카테고리별(화장품 / 뷰티 디바이스 / 피부과 시술 / 마사지·기타) 카드로 쌓아 보여주는 구조를 가져온다. 카드는 제목 + 핵심 값 + 보조 설명 3단 위계.
- 반영 포인트: 기록이 없는 날짜를 선택하면 빈 상태 문구를 카드 안에 보여주는 처리를 가져온다.
- 제외: 하단 탭의 쇼핑 탭과 매거진 탭은 커머스·콘텐츠 기능이라 가져오지 않는다.
