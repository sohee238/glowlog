## 달다방 — 글쓰기 기본 화면 (분류 선택 + 본문 + 하단 저장)
- ui_url: https://uibowl.io/name/%EB%8B%AC%EB%8B%A4%EB%B0%A9?patterns=%EA%B8%80%EC%93%B0%EA%B8%B0&imgId=cmuc8yemp0004k0047byaynu7
- 관찰: 상단 내비(뒤로가기 + 가운데 제목) 아래에 둥근 드롭다운("선택해 주세요")으로 분류를 먼저 고르고, 제목 한 줄 입력 → 항목 선택 버튼 + "선택된 항목이 없어요" 빈 상태 박스 → 큰 본문 입력 영역 순으로 위에서 아래로 쌓인다. 하단에 "임시저장"(외곽선) / "저장"(채움) 버튼 2개가 고정된다.
- 반영 포인트: 위→아래 한 화면 스크롤 구조(분류 → 이름 입력 → 본문/메모 → 하단 고정 저장 버튼)를 그대로 가져온다. 아무 것도 선택되지 않았을 때 회색 안내 박스로 빈 상태를 보여주는 방식을 제품·시술 입력 영역에 적용한다.
- 반영 포인트: 저장 버튼은 화면 하단 고정, 채움 스타일로 강조하고 보조 버튼은 외곽선으로 구분한다.
- 제외: 상품 선택 후 쇼핑 연결(구매 연동)과 게시판 선택은 가져오지 않는다.

## 닥터다이어리 — 감정일기 작성 진입 화면
- ui_url: https://uibowl.io/name/%EB%8B%A5%ED%84%B0%EB%8B%A4%EC%9D%B4%EC%96%B4%EB%A6%AC?patterns=%EA%B8%80%EC%93%B0%EA%B8%B0&imgId=cmr7e2vm90003l104b4qrke5b
- 관찰: 크림→연분홍 그라디언트 배경 위에 큰 제목 "감정일기"와 "오늘 당신의 마음은 어땠나요?" 질문형 안내 문구, 중앙 이모지 그래픽, 하단 넓은 라운드 버튼으로 구성된 개인 기록용 화면이다. 정보량을 줄이고 감성적인 톤을 유지한다.
- 반영 포인트: 개인 기록 도구 톤 — "오늘 어떤 관리를 했나요?"처럼 질문형 헤드라인으로 화면을 연다. 파스텔 그라디언트 배경은 Glowlog 아이리데센트 그라디언트 토큰으로 대체한다.
- 반영 포인트: 하단 CTA는 가로 꽉 찬 라운드 버튼 한 개로 단순하게 둔다.

## 럽맘 — 단계형 글쓰기 상세 정보 입력 (칩 그리드)
- ui_url: https://uibowl.io/name/%EB%9F%BD%EB%A7%98?patterns=%EA%B8%80%EC%93%B0%EA%B8%B0&imgId=cmpz031ld000clb04rbv5xeya
- 관찰: 상단 진행 바(2/3) 아래에 "상세 정보를 입력해주세요" 제목, 필수 항목마다 라벨 + 빨간 별표, 드롭다운 필드, 그리고 3열 그리드 칩(행복해요·기대돼요 등)이 이어진다. 선택된 칩은 분홍 테두리 + 연분홍 배경 + 분홍 글자로 표시되고 미선택 칩은 회색 테두리다. 하단에 "이전"(회색) / "다음"(분홍) 버튼이 비활성 톤으로 고정된다.
- 반영 포인트: 카테고리 4종(화장품 / 뷰티 디바이스 / 피부과 시술 / 마사지·기타)을 칩으로 한 번에 노출하고, 선택 상태는 테두리 + 배경 틴트 + 글자색 3가지를 함께 바꿔 구분한다.
- 반영 포인트: 섹션마다 라벨을 칩·필드 위에 두고 필수 표시를 붙인다. 필수 값이 비어 있을 때 하단 저장 버튼을 비활성 톤으로 보여준다.

## 베이비빌리 — 카테고리 선택 바텀시트 (아이콘 칩)
- ui_url: https://uibowl.io/name/%EB%B2%A0%EC%9D%B4%EB%B9%84%EB%B9%8C%EB%A6%AC?patterns=%EA%B8%80%EC%93%B0%EA%B8%B0&imgId=cmpw5pbjo0009kw04ahuelv4d
- 관찰: 작성 화면 위에 딤 처리 후 바텀시트가 올라오고, "카테고리를 선택해주세요" 제목 아래 아이콘 + 텍스트가 들어간 알약형 칩이 가로로 줄바꿈 배치된다. 선택된 칩은 어두운 채움 + 흰 글자로 반전된다.
- 반영 포인트: 칩 안에 작은 아이콘을 앞에 붙여 카테고리를 빠르게 알아보게 한다 (화장품·디바이스·시술·마사지 아이콘).
- 반영 포인트: 알약형(완전 라운드) 칩 + 가로 줄바꿈 배치로 4개 카테고리를 한두 줄에 담는다. 바텀시트 대신 본문 상단에 바로 노출해 단계를 줄인다.

## 럽맘 — 글 작성 사진추가 영역 (최대 장수 카운터)
- ui_url: https://uibowl.io/name/%EB%9F%BD%EB%A7%98?patterns=%EA%B8%80%EC%93%B0%EA%B8%B0&imgId=cmpz031ul000ylb04j1ihdvtc
- 관찰: "사진추가" 섹션 제목 아래 정사각 타일이 가로로 나열된다. 첫 타일은 점선 테두리 + "+" + "1/4" 장수 카운터, 그 옆에 첨부된 사진 썸네일이 라운드 모서리로 놓이고 우상단에 원형 X(삭제) 버튼이 붙는다. 하단에 넓은 분홍 "작성 완료" 버튼이 고정된다.
- 반영 포인트: 사진 첨부는 정사각 타일 가로 나열 — 첫 타일은 점선 추가 버튼 + 현재 장수/최대 장수 표시, 첨부 사진은 썸네일 + 우상단 삭제 버튼으로 구성한다.
- 반영 포인트: 사진 타일 모서리는 카드와 같은 라운드 토큰으로 맞춰 통일감을 준다.
- 제외: 해시태그·추천태그 입력과 하단 탭바의 커뮤니티 메뉴는 가져오지 않는다.

## 집지켜 — 질문 작성 화면 (상단 칩 + 본문 + 사진 추가)
- ui_url: https://uibowl.io/name/%EC%A7%91%EC%A7%80%EC%BC%9C?patterns=%EA%B8%80%EC%93%B0%EA%B8%B0&imgId=cmubauaow0017l504hqvzprrb
- 관찰: 상단에 회색 사각 칩(공공임대·전세·월세 등)이 줄바꿈 배치되고, 그 아래 연회색 배경의 큰 라운드 텍스트 영역("10글자 이상 입력해 주세요"), "사진 추가" 라벨 + 회색 정사각 "+" 타일, 하단에 비활성 회색 버튼이 이어진다.
- 반영 포인트: 메모 입력은 테두리 없이 연한 배경 면 + 큰 라운드로 처리해 입력 영역을 부드럽게 구분한다 (Glowlog에서는 frosted glass 카드 면으로 대체).
- 반영 포인트: 칩 → 본문 → 사진 → 하단 버튼의 순서가 화면 1 흐름(카테고리 → 입력 → 사진 → 메모 → 저장)과 같아 섹션 간격 리듬을 참고한다.
- 제외: 답변 이후 수정 불가 안내와 외부 게시 버튼은 가져오지 않는다.
